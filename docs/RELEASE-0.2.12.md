# 时光相册 0.2.12

Windows 10/11 x64 便携版，包含 .NET 10 桌面运行时。下载 `ShiguangAlbum-0.2.12-win-x64.zip`，完整解压后打开 `运行程序-0.2.12/拾光照片.exe`。

## 本次更新

- 普通单击定位照片，双击、Enter 或空格打开预览。
- 新增明确的“多选”入口和“完成”退出操作。多选后可加入相册、收藏、移出相册或移入回收站。
- Delete 打开所选项目的回收站确认，取消保留勾选，执行后支持撤销。
- 方向键在网格移动，Page Up / Page Down 翻页，支持跨越 240 项加载边界。大图预览增加上下键与翻页键切换。
- 批量工具栏适配最小窗口，焦点与勾选分别显示。

本次 GitHub 发布同时包含 0.2.10 的文件安全与异常恢复改进，以及 0.2.11 的幻灯片、背景音乐功能。

## 初次使用与升级

首次使用点击“添加来源目录”，选择已有照片或视频文件夹。程序在运行目录的同级目录创建 `数据/`，保存索引、相册和设置。

升级时先退出旧版，将新版 `运行程序-0.2.12/` 放到原 `数据/` 的同级目录。已有媒体库也可通过“设置 → 备份与迁移 → 打开媒体库”重新打开。

便携包包含快速入门、使用说明、版本说明和素材许可。SHA-256 校验文件与 ZIP 一同提供。

## 验证与兼容范围

- 完整 17 组本地隔离回归通过，包含 396 条具名检查及两组状态和性能验证。
- 20 项设计静态检查通过。三种主题、最小窗口和实际桌面键盘操作已检查。
- 删除撤销、加入相册及浏览流程使用生成的测试素材验证，并检查原文件哈希。
- Ctrl+A 勾选当前已加载项目。HEIC、HEVC 等格式依赖 Windows 解码组件。

完整说明和验证摘要位于源码仓库的 `使用说明.md`、`docs/GALLERY-0.2.12.md` 和 `docs/validation-0.2.12.json`。
