# 0.2.10 文件安全修复

日期：2026-11-10。

本次修复四项：缓存路径越界、来源重连误认、异常恢复未接入、未决任务与扫描冲突。

- 缓存键只接受有限长度的字母、数字、连字符、下划线，保留旧版安全 ID；小图、大图路径统一验证目录边界及重解析点。写索引、打开数据库和外部媒体库时也校验项目 ID。
- 来源重连比较完整文件哈希。缺少历史哈希时从仍在线的原位置建立校验记录；原位置离线且没有哈希时明确拒绝，保留原连接。全部文件通过后事务更新引用，预览和视觉指纹失效并重建。
- 主窗口加载时只对账已经完成的移动，不自动移动或删除剩余源文件。有未决任务时停止自动预览，显示持续提示，并在设置的媒体库页显示任务恢复。恢复窗口列明操作、源位置和目标位置，关闭默认聚焦；继续或取消由用户选择。操作失败后保留日志与错误。
- 当前索引器在任何写入前拒绝未决操作，防止中断恢复产生第二条路径记录；任务完成后恢复扫描。

自动回归新增 `--safety-test` 和 `--recovery-smoke`，安全检查进入 `自测.ps1 -CoreOnly`，恢复入口检查进入完整验收。测试使用独立生成素材，包含恶意 ID、同大小不同内容、离线身份未知、预览失效、中断删除/恢复、扫描保护、安全取消与启动提示。

UI 沿用 `DESIGN_SYSTEM.md` 的 SettingRow、NoticeBar、共享按钮、主题和安全默认焦点。恢复列表采用主题资源、中文状态与可换行路径。修改前证据为本地 `验证/审查-20261109/ui-render-data/02-设置-媒体库.png`；本次前后验收结果、渲染图片和限制记录见本地 `验证/修复-20261110/验收记录.md`。

本版未处理另外两项审查建议：永久删除的大图缓存遗留、不可解码媒体的完全重复检测。真实键盘、所有 DPI、多屏与读屏认证仍需单独验收；程序事件测试和 WPF 渲染不等于物理键盘与系统桌面截图。
