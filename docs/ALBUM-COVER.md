# 自定义相册封面

2026-11-15 · 0.2.14 开发分支，尚未发布。对应 [Issue #2](https://github.com/dayesann/shiguang-album/issues/2) 的封面需求。

1. 打开相册，点选一张照片，或用方向键定位。
2. 在网格上方选择「相册封面 → 将当前照片设为封面」。
3. 返回相册总览即可看到新封面。要重新自动选图，选择「相册封面 → 恢复自动封面」。

只能选择相册内预览可用的照片。封面离线或在回收站时，应用暂用自动封面；照片恢复后会接着用原来的封面。将照片移出相册会清除其封面引用。相册备份会保存选定的封面；导入时若找不到原照片，继续使用自动封面。操作只更新媒体库记录。

入口复用 [设计系统](../DESIGN_SYSTEM.md#相册自定义封面)的轻量按钮、标准菜单和 NoticeBar。用演示素材实际核对了[改动前](images/album-cover-before.png)、[设置成功](images/album-cover-set.png)和[总览显示](images/album-cover-overview.png)；也用鼠标定位照片，再用方向键与 Enter 保存封面。

Windows 构建、20 项静态检查、6 组核心回归、31 项 WPF 相册检查均通过。覆盖浅色、深色、跟随系统和最小窗口，以及没有自定义封面、处于多选、照片离线或被移出相册等情况。测试确认原文件路径和哈希不变。尚未覆盖所有 Windows 缩放比例和读屏软件。
