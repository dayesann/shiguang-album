# 媒体网格鼠标框选

2026-11-15 · 0.2.14 开发分支，尚未发布。对应 [Issue #2](https://github.com/dayesann/shiguang-album/issues/2) 的鼠标框选需求。

1. 在媒体网格点击「多选」。
2. 从照片上或网格空白处按住左键拖动。框内项目会显示勾选，底部显示已选数量。
3. 松开鼠标确认这次选择。普通拖动替换已有选择；按住 Ctrl 再开始拖动，可以在已有选择上追加。

拖动中按 Esc 只取消这次框选，并恢复拖动前的选择。滚动、切换窗口或网格变化时也会取消当前框。一次只框选当前可见的网格；要跨屏选择，可以滚动后按住 Ctrl 分次追加。

沿用 [设计系统](../DESIGN_SYSTEM.md#媒体网格鼠标框选) 的选中色、勾选标记和批量操作条。框选本身不改动照片或视频。普通浏览、单击勾选和方向键／空格操作仍可用。

用隔离演示库核对了 [改动前](images/marquee-before.png)、[浅色最小窗口](images/marquee-light.png) 和 [深色最小窗口](images/marquee-dark.png)。实际从空白处反向拖动，确认松开鼠标后保留三个勾选；再次从照片内拖动替换成一个勾选，并用 Esc 退出多选。

Windows 构建、20 项设计静态检查、6 组核心回归和 40 项 WPF 相册检查通过。回归覆盖 Ctrl 追加、缩小选区、拖动时 Esc 恢复、网格刷新、跟随系统及原文件哈希不变。高对比度沿用系统色映射，未单独切换系统高对比度，也未验证全部 DPI 或读屏软件。
