# 0.2.12 相册浏览与键盘多选

日期为 2026-11-14。新版程序位于 `成品/运行程序-0.2.12/`，项目目录内五个启动快捷方式已指向该版本。

## 使用方式

- 普通单击只定位照片。焦点显示独立轮廓，双击、Enter 或空格打开预览。
- 网格右上方提供“多选”。开启后显示勾选圆圈与底栏，单击、空格或 Enter 切换当前项目的勾选。点击“完成”或按 Esc 清除勾选并退出。
- Delete 在多选网格或批量操作栏获得焦点时打开回收站确认。确认展示数量、大小和缩略图，默认聚焦“取消”。取消后保留勾选，执行后可撤销。
- “加入相册”成功后回到浏览。“移出相册”只移除当前相册引用。底栏允许换行，空选择时操作禁用。
- 方向键按网格位置移动焦点，Page Up / Page Down 翻页。键盘导航可以跨越 240 项加载边界。Tab 进入或离开网格，输入框继续处理自己的编辑按键。
- 大图预览支持上下、左右和 Page Up / Page Down 换片。

单击只定位、双击打开的行为按本次需求采用。相册加入成功后自动退出多选，便于继续浏览。
