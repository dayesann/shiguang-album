# 拾光照片 0.2.15

- **自定义相册封面**：在相册内选中一张照片，用「相册封面」设为封面或恢复自动封面。封面设置随相册备份保留。（#3）
- **鼠标框选**：在「多选」模式下拖动选择当前可见的照片。Ctrl + 拖动追加；拖动中按 Esc 可恢复之前的选择。（#4）
- **回收站全选**：点击「全选」或按 Ctrl+A 勾选全部项目，包括屏幕下方的条目。永久删除仍需确认，默认焦点在「取消」。（#7）
- **快捷键说明**：在「设置 → 快捷键」按场景查看操作。现有快捷键保持不变。（#8）

## 下载与升级

下载 `ShiguangAlbum-0.2.15-win-x64.zip`，适用于 Windows 10/11 x64，内含 .NET 桌面运行时。

- **0.2.14**：打开「设置 → 关于 → 软件更新」，检查并下载 0.2.15，待当前任务完成后重启更新。
- **0.2.13**：先在软件里更新到 0.2.14，再检查 0.2.15；也可直接手动替换为 0.2.15。
- **0.2.12 或更早**：退出旧版，把完整的 `运行程序-0.2.15` 文件夹放在原 `数据` 文件夹旁边，再打开新版。原照片、相册和索引可以继续使用。
