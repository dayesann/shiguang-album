# 拾光照片 0.2.13

- “设置 → 关于 → 软件更新”新增手动检查入口。应用启动后会在后台检查，长时间运行时每六小时检查一次。发现正式版后显示提示，可下载、取消下载或稍后重启。勾选“自动下载更新”可在后台准备新版。
- 更新包在本地校验 SHA-256，解压到独立的新版程序目录。用户选择重启后沿用原媒体库和来源路径。旧程序保留，从已有快捷方式启动时会接续打开已启用的新版。
- 如果当前有扫描或整理任务，请等待完成再重启。下载失败或校验失败不切换到新版。

0.2.12 及以前的版本没有更新入口。第一次升级请退出旧版，把完整的 `运行程序-0.2.13` 放在原有 `数据` 目录的旁边，打开其中的 `拾光照片.exe`。以后可在软件里更新。
