# 验证基线

2026-11-08，0.2.9 在 Windows 实际桌面完成 13 组隔离进程回归，全部成功退出：295 条具名检查、20 项静态设计检查及十万条合成索引性能场景通过。

覆盖后台扫描与托盘、退出后重新打开、紧凑控件及撤销、媒体库迁移、完整流程、核心查重与恢复、媒体索引、浏览界面、外观设置、设计验收、旧库升级、十万索引和视频控制。

实际桌面检查包括常规设置的 Tab/空格操作、关闭到后台、再次启动恢复同一窗口、明确退出及媒体库锁释放。后台测试使用 240 张生成的 JPEG，验证窗口隐藏时索引和预览完成，来源哈希保持一致。

本次仓库整理仅调整构建／测试入口及文档，不修改产品 UI 和媒体逻辑。完整历史报告与截图保留在本地 `验证/`，未上传私人媒体或本地库。

CI 执行 Windows 构建、静态检查及 `-CoreOnly` 的四组无交互核心检查。GUI、托盘、系统选择器、视频、实际 DPI 和键盘验收应在可交互 Windows 桌面另行完成，不能用 CI 通过代替。

十万索引是合成数据性能场景，不代表任意硬盘上首次读取十万张原图的耗时。未完成所有 Windows DPI、所有读屏软件、所有解码格式及系统关机压力组合的认证。
