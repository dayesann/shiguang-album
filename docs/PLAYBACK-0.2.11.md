# 0.2.11 · 幻灯片与背景音乐

日期：2026-11-10。

## 使用与变更

- 顶部“播放幻灯片”从当前照片开始，连续播放当前相册、收藏、时间和搜索范围的照片；视频保留独立播放器。普通双击照片保持暂停。
- 预览支持播放/暂停、3/5/8/12 秒停留、循环、背景音乐开关、音量与音乐来源选择。默认使用原创器乐《拾光》，也可选择本地音乐。
- 每张成功显示后才重新计时；失败暂停，避免慢解码时不断跳片。关闭循环后末张结束停止；手动切换重新计时。
- 暂停或关闭预览同时暂停/关闭音乐；BGM 独立循环，缺失或损坏音乐提示恢复操作，不阻止照片自动播放。
- 播放偏好保存在当前库，随媒体库备份保存；外部音乐只保存路径引用，不复制音乐文件。照片、视频和音乐原件不变。
- 空格播放/暂停、左右方向键换片、F11 全屏、Esc 退出全屏或预览；下拉框、音量和按钮保留原生键盘操作。
- 主窗口按索引定位当前照片，避免在加载分页后从错误照片开始。
- 新版程序位于 `成品/运行程序-0.2.11/`。本地五个启动快捷方式已更新，保留演示/设置/控件样板参数。

## 已知范围

- 本轮自动连续播放范围是照片，混合相册中的视频跳过。
- 本地音乐依赖 Windows 解码组件；未逐一验证所有 MP3/M4A/AAC 编码。音乐错误不会停止照片播放。
- 30 项专项包含缺失文件和解码错误；系统文件选择器未完成所有键盘路径的人工抽检。
- 已检查实际桌面、三种主题、700×500 最小预览与全屏；未切换所有 Windows DPI 和真实高对比度设置。共享令牌沿用既有高对比支持。
- 声音验证使用媒体引擎状态与播放位置推进，未对用户的物理扬声器、实际听感或设备切换作保证。

原创音乐由 `工具/生成内置音乐.ps1` 重现，不引用第三方歌曲或采样。
