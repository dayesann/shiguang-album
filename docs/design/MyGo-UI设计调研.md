# MyGo Native UI 设计调研与时光相册应用建议

日期：2026-11-08  
范围：官方 UI 文档；按钮、工具栏、表单、侧栏、删除提示的浏览器实际预览。此次只形成研究结论，不修改应用界面。

## 结论

MyGo 适合作为时光相册的控件密度、工具栏、表单和反馈交互参考。建议以 Eagle 的媒体组织和照片排版为产品骨架，用 MyGo 的紧凑控件降低界面重量，通过现有 WPF 组件统一实现。

它是一套 Go 原生 UI 框架及控件文档，并非可直接导入 WPF 的主题包。官方描述使用 GPU 自绘，Windows 后端为 Direct3D 11。采用外观和行为规则，无需更换技术栈。其性能数据也不能直接推导为本项目性能。

## 实际预览观察

以下是本次浏览器预览中的可见观察，并非对全部平台或主题的认证：

| 部件 | 可见特点 | 时光相册的应用建议 |
|---|---|---|
| 按钮 | Cancel、Save 和垃圾桶图标共用相近高度，Save 使用单一强调色；弱灰底、细边框、小圆角 | 区分提交按钮、工具按钮、危险确认；控制字重和内边距，避免靠大色块突出每个动作 |
| 工具栏 | 返回/前进、局部选择、末端动作形成一条紧凑横栏；分隔线清楚 | 常用工具使用透明图标按钮，提示在悬停出现；窄窗口将低优先级操作收进菜单 |
| 表单 | 标签列与控件列对齐，说明和错误贴近所属字段；组标题简短 | 设置使用短分组和整齐的设置行，错误就近展示，减少每项包一张卡片的做法 |
| 侧栏 | 分组标题、统一图标、低饱和选中背景、靠右数量 | 使用统一导航行；相册分组可折叠；数量与名称各自对齐 |
| 删除提示 | 背景变暗，标题、简短后果、两枚按钮构成紧凑弹层，内容不留大块空白 | 采用相同的信息层级，额外展示照片数量和范围；永久删除使用危险样式，取消默认聚焦 |

预览入口：[按钮](https://mygo.egoist.dev/docs-demo?demo=button)、[工具栏](https://mygo.egoist.dev/docs-demo?demo=toolbar)、[表单](https://mygo.egoist.dev/docs-demo?demo=form)、[侧栏](https://mygo.egoist.dev/docs-demo?demo=sidebar)、[删除提示](https://mygo.egoist.dev/docs-demo?demo=alert-dialog)。

## 文档中值得采用的规则

1. **密度统一由主题管理。** `Spacing` 默认 4，3 表示紧凑，5 表示宽松；字号、圆角、滚动条尺寸同属主题。应把尺寸做成资源，而非逐个页面改高度。[主题](https://mygo.egoist.dev/docs/ui/styling)
2. **工具栏有完整行为。** 普通工具静息时弱化外壳，空间不足从末端进入菜单；Tab 进入工具栏后，方向键在工具间移动。[工具栏](https://mygo.egoist.dev/docs/ui/toolbar)
3. **仅图标按钮有名称与提示。** 视觉简洁不以牺牲识别和键盘操作为代价。[按钮](https://mygo.egoist.dev/docs/ui/button)
4. **年月日属于单个互斥选择组。** 分段控件作为一个 Tab 停靠点，方向键选择选项，向辅助技术暴露选择关系。[分段控件](https://mygo.egoist.dev/docs/ui/segmented)
5. **反馈按严重度分层。** 常规结果采用短暂提示，可撤销动作提供撤销入口；重要决定才使用模态提示。[Toast](https://mygo.egoist.dev/docs/ui/toast)、[Alert](https://mygo.egoist.dev/docs/ui/alert-dialog)
6. **可调整面板保存用户选择。** Split 支持拖动、键盘调整、双击重置及恢复之前的尺寸。[分栏](https://mygo.egoist.dev/docs/ui/split)
7. **测试关注真实可点击性。** 官方测试工具会检测控件是否有可见区域、中心是否被遮挡；这比单独调用事件或检查文案存在更接近真实操作。[测试](https://mygo.egoist.dev/docs/ui/testing)

## 需要保留的产品差异

### 照片排列

MyGo `GridView` 按最小项目宽度确定列数，平分余宽，使用指定行高，并虚拟化可见内容。它的默认行为仍是等宽格子，不能据此认定能够实现 Eagle 式等高、变宽的照片排版。时光相册继续采用保持原始宽高比的自适应行；最后一行不强行拉伸，全景图和长截图需单独检查。[Grid view](https://mygo.egoist.dev/docs/ui/grid-view)

### 删除安全

官方 Alert 示例把最后一个按钮作为强调色默认操作，并由 Enter 触发。这个通用约定不适合直接用于永久删除私人媒体。时光相册保留安全焦点与危险确认；普通移入回收站是否可以降低确认频次，需要先保证撤销能恢复文件和相册关系。批量清理继续提供明确的范围审阅。[Alert dialog](https://mygo.egoist.dev/docs/ui/alert-dialog)

### 视频播放

官方 `Video` 用于短片、动图或网格预览；当前文档明确说明视频没有声音，系统 H.264、HEVC、VP9、AV1 解码尚未包含。因此不作为完整播放器替代方案。现有播放器继续承担音量、进度、倍速、全屏、格式兼容与错误恢复。[Video](https://mygo.egoist.dev/docs/ui/video)

### 性能结论

官方性能表测量的是 Apple M5 上 `ui.Tester` 的稳态 CPU 帧成本，不包含 Windows 原生窗口进程总内存和 GPU 资源，也没有比较其他 GUI 框架。不能用这些数字承诺换框架会改善照片导入、解码或查重速度。[性能范围](https://mygo.egoist.dev/docs/ui/performance)

## 建议形成的项目规范

以下是本项目建议值，不是对 MyGo 默认尺寸的转述：

| 令牌/组件 | 建议 |
|---|---|
| 工具栏图标 | 16–18 DIP；32 DIP 点击区域；静息透明 |
| 常规按钮 | 30–32 DIP 视觉高度；中文 13–14 DIP；主要操作使用唯一强调色 |
| 导航 | 34–38 DIP 视觉行高；图标与文字基线统一；用户文字缩放后允许增高 |
| 分段切换 | 28–30 DIP；整组位置稳定；方向键可操作 |
| 间距 | 采用 4/8/12/16/24 的统一级别；紧凑密度由一处资源调整 |
| 设置 | 名称、短说明、右侧控件组成设置行；大说明只在决策需要时展开 |
| 提示 | 普通成功就近提示；可恢复删除提供撤销；永久删除独立确认 |
| 桌面适配 | 浅色、深色、跟随系统与高对比；不能用统一缩小字号掩盖布局问题 |

## 下一轮实施和验收顺序

先建立一个真实 WPF 控件样板页，包含按钮、工具栏、分段控件、设置行、提示、删除确认与三种主题。验证悬停、按下、键盘焦点、禁用、长中文、文字缩放和窄窗口；确认统一组件后再用于七类窗口。

主窗口还需核对：年月日稳定居中、工具栏自动溢出、来源/相册切换保留合理的浏览状态、照片不裁切、最后一行不夸张放大。主题与 UI 控件调整不得触碰原始媒体目录。

总体研究依据：[MyGo Native UI](https://mygo.egoist.dev/docs/ui)。框架能力来自官方文档，视觉特点来自上述实际预览；本次未安装 MyGo 原生程序，未做 Windows 性能、中文输入或读屏认证。
